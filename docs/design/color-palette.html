Creator Kit / Fluent Theme Object
Paste this into your App.OnStart to define an AppTheme variable compatible with the Creator Kit theme components. Reference individual slots with ColorValue(AppTheme.palette.themePrimary).
Set(
  AppTheme,
  {
    palette: {
      themePrimary:     "#246FAE",  // Accent blue — buttons, links
      themeLighterAlt: "#F7FBFE",  // Lightest accent tint
      themeLighter:    "#DEF0F9",  // Very light accent
      themeLight:      "#A8D3ED",  // Light accent
      themeTertiary:   "#68AAD8",  // Medium accent
      themeSecondary:  "#3D8BCB",  // Secondary accent
      themeDarkAlt:    "#1B5A8E",  // Button hover
      themeDark:       "#003E6B",  // Dark accent
      themeDarker:     "#00213A",  // Darkest accent
      neutralLighterAlt:"#F7F9FB",  // Panel background
      neutralLighter:  "#F0F4F8",  // Page background
      neutralLight:    "#E8ECF1",  // Row hover, subtle bg
      neutralQuaternaryAlt:"#E2E7ED",// Borders, dividers
      neutralQuaternary:"#C5CDD6",  // Disabled borders
      neutralTertiaryAlt:"#B0BAC5", // Scrollbar, toggle tracks
      neutralTertiary: "#9CAAB9",  // Placeholder text
      neutralSecondary: "#7A8BA0", // Secondary text
      neutralPrimaryAlt:"#4D6480",  // Icon color
      neutralPrimary:  "#3B4F6B",  // Body text
      neutralDark:     "#213455",  // Headings, primary text
      black:          "#162740",  // Strongest emphasis
      white:          "#FFFFFF"   // Cards, content areas
    }
  }
);
Set(AppThemeJson, JSON(AppTheme, JSONFormat.IndentFour));

How to Apply

Approach Steps
Modern Theme
(Fluent v9)		 1. Enable Modern controls and themes in Settings → Updates → New
2. Click Themes → Add a theme
3. Set primary seed color to #246FAE
4. Reference via App.Theme.Colors.Primary etc.
Creator Kit
(Fluent UI)		 1. Import the Creator Kit solution
2. Paste the Set(AppTheme, ...) block into App.OnStart
3. Pass AppTheme to component Theme properties
4. Pass AppThemeJson to code components
ColorPalette Variable
(Classic controls)		 1. Paste Set(ColorPalette, ...) into App.OnStart
2. Reference via ColorPalette.Navy900, ColorPalette.Blue600, etc.
3. Applies to all classic and custom controls
